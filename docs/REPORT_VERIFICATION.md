## 不按报告建议修改的典型项

- **R1 191：`FluentIcon.CONSTRACT` 不存在。** 本地 qfluentwidgets 中存在 `CONSTRACT`，不存在 `CONTRACT`；报告建议反而导致启动错误。
- **R1 37：Windows 的 `ansi` codec 无效。** 本机 `codecs.lookup('ansi')` 返回 `mbcs`。不能按“所有平台均无效”的结论改动 Windows 行为。
- **R1 55：payload 中 action 能覆盖请求。** `request(self, action, **payload)` 接收重复 action 会在 Python 参数绑定阶段报错，不会进入请求体。
- **R1 34：自动检测 zh 一定导致 SMI KeyError。** 当前 writer 已对 zh 单独处理。其他未知语言的兜底另外修复。
- **R1 9、11、26：强制英文整词边界、拒绝全部零时长词、强制 sherpa 三个组件同一量化。** 这些前提不成立：中文/子词可以相邻，测量可产生同时间戳，合法分发可以采用混合精度。保留真实时间，不伪造词尾。
- **R1 118：PyAV stereo 返回 frames×2。** 当前 split_stereo 路径返回 left/right，转数组为 2×frames。保留正确的立体声路径，修复单声道形状。
- **R1 125、57：统一锁住所有推理或把关闭和请求使用同一锁。** 当前远程请求已串行；关闭必须能解除阻塞中的请求。取消通信测试验证了这一路径，同锁可能造成无法取消。原生 CT2 的 num_workers 不应无证据禁用。
- **R1 151：没有 min/max speaker 校验。** 当前参数转换已有 max 至少为 min 的处理。
- **R2 264：没有显式 HF token 就必须停止。** 凭据还可来自环境/本地登录；直接禁止会破坏合法加载。保留加载错误，并明确处理 pipeline 为 None。
- **R2 228：unfinished 版本翻译必然破坏占位符。** Qt 对未完成项回退源文本；不填写没有核验过的翻译或更改占位符。
- 未使用导入、变量命名、未来布局项/配置枚举变化、未来依赖版本等建议，不能据此断言当前存在可复现缺陷。保留已验证的 ROCm 依赖组合，不执行报告建议的安装/降级或任意 DLL 搜索替换。
